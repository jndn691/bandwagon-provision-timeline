## 为什么会触发人工审核？这些操作要避开

买之前最好了解一下哪些行为容易触发风控：

1. **购买时挂了代理或 VPN**。这是触发人工审核最常见的原因，系统看到你的 IP 来自境外，就会觉得奇怪。购买的时候关掉代理，用真实的网络环境下单。
2. **注册信息填得太假**。国家一定要选 China，其他信息可以不完全真实，但看起来要像那么回事。
3. **历史欺诈记录**。如果这个邮箱或 IP 之前有过被认定欺诈的记录，再次下单就很容易被盯上。

这三个注意点做到位，95% 的情况都是几分钟自动开通，不会遇到人工审核。

## 订单状态解读：四种状态各是什么意思

在 My Services 里看到的状态单词，有时候会让人看不懂：

**Active**：正常运行中。这是你想要的状态。

**Suspended**：VPS 被暂停了。最常见的原因是续费账单超过 7 天未支付，系统自动暂停，但数据还在。付款之后会重新激活。

**Terminated**：VPS 已被终止删除。在 Suspended 状态下长时间不续费，系统最终会把机器删掉，数据也没了。

**Fraud**：系统判定订单有问题。这时候需要联系客服处理。

## 开通后第一步：如何登录你的 VPS

VPS 开通后，邮件里会有两个关键信息：**IP 地址**和 **SSH 端口**。
